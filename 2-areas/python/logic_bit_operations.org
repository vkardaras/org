* Bitwise Operators

- Conjunction =&=
- Disjunction =|=
- Negation =~=
- Exclusive =^=

#+begin_src python
  print(bin(15))
  print(bin(22))
#+end_src

#+RESULTS:
: 0b1111
: 0b10110

#+begin_src python
  result = 15 & 22
  print(result)
  print(bin(result))
#+end_src

#+RESULTS:
: 6
: 0b110

#+begin_src python
  result = 15 | 22
  print(result)
  print(bin(result))
#+end_src

#+RESULTS:
: 31
: 0b11111

#+begin_src python
  result = 15 ^ 22
  print(result)
  print(bin(result))
#+end_src

#+RESULTS:
: 25
: 0b11001

** Bit Shifting

- Bit Shift Right =>>=
- Bit Shift Left =>>=

#+begin_src python
  print(22 >> 1)
  print(22 << 1)
#+end_src

#+RESULTS:
: 11
: 44

- ~print(22 // 2)~ -> ~print(22 >> 1)~
- ~print(22 // 4)~ -> ~print(22 >> 2)~
- ~print(22 * 2~) -> ~print(22 << 1)~
- ~print(22 * 4)~ -> ~print(22 << 2)~
